# market-intelligence-poc

**项目定位：** 从真实商业决策出发，验证可复用的 AI 市场研究与消费者洞察能力；不预先承诺技术架构或最终产品形态。

**首个案例：** 美国婴幼儿看护监控产品市场机会研究（`cases/us-baby-monitor/`）。萤石 C6c 类产品仅作为触发研究的参考线索，不是已批准的开发规格。

## 核心原则

- **先判断是否值得进入市场，再决定是否做产品；若做，再决定做什么产品。**
- 市场存在需求 ≠ 新进入者有机会 ≠ 我们能盈利。
- 社媒讨论适合发现需求、行为和痛点，不能单独证明市场规模、销量或利润。
- 研究要容许得出“暂不进入”；不能为了项目立项反向筛选证据。
- 手工流程和证据先行，之后再决定哪些环节需要 AI、检索、工作流或 Agent。
- 文档状态、结论依据与不确定性必须可追溯；不把计划当成已完成的事实。
